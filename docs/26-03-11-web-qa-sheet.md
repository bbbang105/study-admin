**작성일:** 2026-03-11  
**대상:** `packages/web`  
**목적:** 화면별이 아니라 실제 사용자 동작 기준으로 빠르게 수동 QA를 수행하기 위한 체크시트

## 사용 방법

- 각 항목은 `사전조건 -> 절차 -> 기대결과` 순서로 확인한다.
- 결과 기록은 아래 상태값 중 하나를 사용한다.
  - `PASS`: 기대결과와 동일
  - `FAIL`: 재현 가능한 문제 확인
  - `N/A`: 현재 데이터나 권한상 확인 불가
- 버그를 적을 때는 `화면 / 재현 절차 / 실제 결과 / 기대 결과 / 콘솔 에러`를 함께 남긴다.
