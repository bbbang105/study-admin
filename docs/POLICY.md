# 큐스팅 4th 스터디 운영 정책

> 최종 업데이트: 2026-03-16

## 1. 권한 체계

### 사용자 vs 관리자

| 구분 | 인증 방식 | 접근 범위 |
|------|----------|----------|
| 사용자 | Supabase Auth (Discord OAuth) | `/dashboard`, `/posts`, `/ranking`, `/board`, `/members`, `/profile` |
| 관리자 | Discord ID 기반 (`ADMIN_DISCORD_IDS` 환경변수 + DB config) | 사용자 전체 + `/admin/*` |

- 관리자 API는 `withAdminAuth` 래퍼로 보호 (미인증 401, 비관리자 403)
- 관리자/사용자 모드 전환은 헤더 프로필 드롭다운에서 가능

### 멤버 상태별 접근 권한

| 상태 | 플랫폼 접근 | 출석 대상 | 벌금 대상 | 점수 부여 | 비고 |
|------|-----------|----------|----------|----------|------|
| `pending_approval` | `/pending`으로 차단 | X | X | X | 온보딩 후 기본 상태 |
| `active` | 전체 허용 | O | O | O | 관리자 승인 시 전환 |
| `inactive` | `/inactive`로 차단 | X | X | X | 관리자가 비활성화 |
| `dormant` | 전체 허용 | X | X | X | 1회 사용 가능, 4회차(8주) 후 자동 복귀 |
| `ob` | 전체 허용 | X | X | X | OB/졸업생 |
| `withdrawn` | 접근 차단 | X | X | X | soft delete, 데이터 보존 |

### 온보딩 필수

- 디스코드 OAuth 로그인 후 온보딩 미완료 시 `/profile/onboarding`으로 리다이렉트
- 필수: 이름, 닉네임, 파트, 블로그 URL, 관심 분야(3~6개), 자기소개(100자+), 포부
- 완료 후 `pending_approval` → 관리자 승인 대기

## 2. 회차 및 출석

### 회차 구조

| 항목 | 규칙 |
|------|------|
| 1회차 | 2주 (14일) |
| 시작 | 월요일 00:00 KST |
| 마감 | 다음 월요일 00:00 KST (2주 후) |
| 지각 마감 | 화요일 00:00 KST (마감 후 +1일) |

### 출석 판정

| 상태 | 조건 | 시점 |
|------|------|------|
| `PENDING` | 회차 시작 시 active 멤버 전원 | 자동 |
| `SUBMITTED` | 월요일 00:00까지 블로그 포스트 발행 | RSS 수집 시 자동 |
| `LATE` | 월요일 00:00 ~ 화요일 00:00 사이 발행 | RSS 수집 시 자동 |
| `ABSENT` | 화요일 00:00까지 미발행 | 매주 화 00:00 자동 처리 |

- RSS 수집은 5분 간격으로 동작
- 수동 글 등록(`/api/posts/manual`)도 동일한 출석 판정 적용
- 이미 `SUBMITTED`/`LATE`/`ABSENT` 상태면 변경하지 않음 (PENDING일 때만 전환)

### 벌금

| 유형 | 금액 | 부과 시점 |
|------|------|----------|
| 지각 (`late`) | 3,000원 | 지각 마감 기간 내 제출 시 |
| 결석 (`absent`) | 5,000원 | 지각 마감 이후 미제출 시 |

- 회차당 멤버당 벌금 1건 (unique 제약)
- 벌금 상태: `PENDING` → `PAID` / `WAIVED`
- 납부 확인: 디스코드 DM 버튼("납부 완료") 클릭 → DB 반영
- 관리자 면제 가능 (`WAIVED`)

## 3. 활동 점수

### 배점 및 상한

| 활동 | 타입 | 점수 | 일일 상한 | 부여 위치 |
|------|------|------|----------|----------|
| 블로그 포스트 발행 | `blog_post` | +30 | 60 (2편) | 봇 (RSS 수집) |
| 게시판 글 작성 | `board_post` | +10 | 20 (2편) | 웹 API |
| 포스트 댓글 작성 | `post_comment` | +5 | 20 (4개) | 웹 API |
| 게시판 댓글 작성 | `board_comment` | +2 | 10 (5개) | 웹 API |
| 포스트 조회 | `post_view` | +3 | 15 (5개) | 웹 API |
| 관리자 수동 | `admin_manual` | 자유 | 없음 | 웹 API (관리자) |

일일 최대 (관리자 제외): 125pt

### 어뷰징 방지

| 규칙 | 적용 대상 |
|------|----------|
| 본인 글 댓글 점수 미부여 | 포스트 댓글, 게시판 댓글 |
| 본인 글 조회 점수 미부여 | 포스트 조회 |
| 같은 포스트 댓글 포스트당 1회 | 포스트 댓글 |
| 같은 글 조회 1회 | 포스트 조회 (post_views UNIQUE) |
| 일일 상한 | 모든 타입 (원자적 CTE) |
| active 멤버만 | 모든 타입 |

### 점수 표시

- **대시보드**: 내 활동 점수 카드 (오늘 진행 상황 + 최근 활동 5개)
- **랭킹**: 총점 기준 단일 랭킹 + 활동 상세 (포스트/조회/댓글/게시글/게시판 댓글)
- **프로필 > 활동 내역**: 전체 점수 내역 (타입별 필터, 무한 로드)

## 4. 디스코드 알림

### 채널 알림

| 알림 | 잡 | 주기 | config key | 디스코드 채널 | 내용 |
|------|---|------|-----------|-------------|------|
| 새 글 알림 | `rss-poll` | 5분마다 | `announcement_channel_id` | #새-글-알림 | 📝 포스트 제목, 작성자, URL, 회차 |
| 회차 시작 | `round-start` | 매주 월 00:00 | `notice_channel_id` | #공지사항 | 🚀 회차 시작, 기간, 마감일, active 멤버 멘션 |
| 회차 리포트 | `round-report` | 매주 화 00:05 | `notice_channel_id` | #공지사항 | 📊 제출률/지각/결석 통계, MVP |
| 주간 랭킹 | `weekly-ranking` | 매주 일 22:00 | `ranking_channel_id` | #주간-랭킹 | 🏆 주간 활동 점수 Top 15 |
| 벌금 납부 알림 | DM 버튼 클릭 시 | 즉시 | `bot_log_channel_id` | #봇-로그 | 💰 납부 완료 알림 (관리자 확인용) |

- `notice_channel_id` 미설정 시 `announcement_channel_id`로 폴백
- 채널 설정은 웹 관리자 `/admin/settings`에서 변경 (새 글 알림 / 공지사항 / 주간 랭킹 / 봇 로그)
- 큐레이션 크롤링/공유 (`curation-crawl`, `curation-share`)는 4기 미사용. 코드는 유지, 스케줄러 등록만 비활성화 예정

### DM 알림

| 알림 | 트리거 | 내용 |
|------|--------|------|
| 지각 기간 독촉 | 매일 10:00 (지각 기간 + PENDING 멤버) | ✍️ "오늘 안에 제출하면 결석은 피할 수 있어요!" |
| 벌금 리마인더 | 매일 10:00 (미납 벌금 + 1일 경과) | ⏰ 지각/결석 벌금 안내 + 경과일 + "납부 완료" 버튼 |

- 벌금 부과 시점(지각 감지 / 결석 처리)에는 DM을 보내지 않음
- 지각 기간(마감일 다음날)에는 아직 미제출인 멤버에게 독촉 DM 발송
- 벌금 리마인더는 화요일 오전부터 미납 벌금을 일괄 안내 (24시간 간격, `lastReminderAt` 추적)
- "납부 완료" 버튼 클릭 → fine 상태 `PAID`로 변경 + 확인 메시지 + #봇-로그에 관리자 알림

## 5. 기타 규칙

### 휴면 (Dormant)

- 1회만 사용 가능 (`dormantUsed` 플래그)
- 최대 4회차(8주)
- 기간 종료 시 자동으로 `active` 복귀
- 휴면 중 플랫폼 접근 가능, 출석/벌금/점수 제외

### 탈퇴 (Withdrawal)

- 사용자 직접 탈퇴 가능 (`/api/profile/withdraw`)
- soft delete: 데이터 보존, `status = withdrawn`
- 재가입 시 관리자 승인 필요

### RSS 수집 기준일

- 2026년 3월 15일 이후 발행된 글만 수집
- `POST_CUTOFF_DATE = '2026-03-15T00:00:00+09:00'`
