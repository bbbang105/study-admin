## 1. 사전 준비

### 필요한 정보

| 항목 | 설명 | 발급 |
|------|------|------|
| 봇 토큰 | Discord Developer Portal → Bot → Reset Token | [Developer Portal](https://discord.com/developers/applications) |
| 서버(길드) ID | 서버 우클릭 → "서버 ID 복사" | 개발자 모드 켜야 함 |

### 봇 권한

봇이 서버에 초대되어 있어야 하며, 다음 권한 필요:

- `MANAGE_CHANNELS` — 채널 생성/수정
- `MANAGE_ROLES` — 카테고리별 권한 설정 (운영 채널 비공개)
- `SEND_MESSAGES` — 메시지 발송
- `EMBED_LINKS` — 임베드 메시지 (RSS 알림, 랭킹 등)
- `VIEW_CHANNEL` — 채널 읽기

### 봇 초대 URL 생성

Developer Portal → OAuth2 → URL Generator:
- Scopes: `bot`, `applications.commands`
- Permissions: Manage Channels, Manage Roles, Send Messages, Embed Links, View Channel

## 3. 채널별 상세 역할

### 📋 정보

| 채널 | 권한 | 용도 |
|------|------|------|
| `#공지사항` | 관리자만 쓰기 | 스터디 규칙, 회차 시작/종료 안내, 일정 변경 |
| `#규칙-벌금` | 관리자만 쓰기 | 벌금 규정, 출석 규칙, 현재 회차 벌금 현황 |

### 🤖 봇-알림

| 채널 | 봇 동작 | 연동 코드 |
|------|---------|----------|
| `#새-글-알림` | RSS 폴링(5분마다)으로 멤버 블로그 신규 글 감지 → 임베드 발송. 회차 시작 시 활성 멤버 멘션 + 기간 안내 | `notification.service.ts` → `announcement_channel` |
| `#큐레이션-브리핑` | 매일 KST 8시, 큐레이션 소스에서 크롤한 트렌드 글 요약 발송 | `curation-crawler.ts` → `curation_channel` |
| `#주간-랭킹` | 매주 월요일, 점수 시스템 기반 주간 순위표 발송 | `score.service.ts` (스케줄러 추가 구현 필요) |

### 💬 커뮤니티

| 채널 | 용도 | 봇 연동 가능성 |
|------|------|----------------|
| `#잡담` | 자유 대화 | 디스코드 메시지 점수 수집 (`DISCORD_MESSAGE` +2점, 일 10점 상한) |
| `#정보-공유` | 기술 아티클, 도구, 리소스 공유 | URL 감지 → DB 저장 (향후) |

### 🔊 음성

| 채널 | 용도 |
|------|------|
| `큐스팅데이` | 정기 스터디 모임 (큐스팅데이) |
| `모각작` | 모여서 각자 작성 (모각작) |
| `잡담` | 자유 음성 대화 |

### 🔧 운영 (관리자 전용)

| 채널 | 용도 | 봇 연동 |
|------|------|---------|
| `#운영-논의` | 규칙 변경, 이벤트 기획, 멤버 관리 | - |
| `#봇-로그` | 봇 동작 로그, 스케줄러 상태 확인 | 봇 에러 핸들러 연동 |
| `#github-pr` | GitHub PR 생성/머지 알림 | GitHub Webhook 연동 |
| `#서버-에러` | 서버 에러 로그 자동 수집 | 에러 모니터링 연동 |
| `#건의사항-알림` | 웹에서 건의사항 글 올라오면 노티 | 웹 → Discord Webhook |
| `🔊 운영-회의` | 운영진 음성 회의 | - |

## 4. 봇 연동 매핑

### DB Config에 저장할 채널 ID

봇은 `study_configs` 테이블에서 채널 ID를 읽어옴 (`getConfigValue()`).

| Config Key | 연결 채널 | 사용처 |
|------------|----------|--------|
| `announcement_channel` | `#새-글-알림` | RSS 신규 글 노티 |
| `notice_channel` | `#공지사항` | 회차 시작/종료 안내 (미설정 시 `announcement_channel`로 폴백) |
| `curation_channel` | `#큐레이션-브리핑` | 큐레이션 트렌드 공유 |

> 채널 생성 후 각 채널 ID를 복사해서 DB에 등록해야 봇이 동작함.
> 웹 관리자 페이지 또는 직접 SQL로 설정 가능.

### 봇 스케줄러 현황

| 스케줄러 | 크론 | 설명 | 채널 |
|----------|------|------|------|
| `rss-poll` | `*/5 * * * *` | 5분마다 RSS 폴링 → 신규 글 감지 | `#새-글-알림` |
| `curation-crawl` | `0 23 * * *` (UTC) | KST 8시 큐레이션 크롤 | - |
| `curation-share` | `0 10 * * *` | 큐레이션 결과 공유 | `#큐레이션-브리핑` |
| `attendance-check` | `0 0 * * 2` | 매주 화 출석 체크 | DM |
| `fine-reminder` | `0 10 * * *` | 벌금 리마인더 | DM |
| `round-report` | `5 0 * * 2` | 회차 리포트 | `#공지사항` |
| `round-start` | `0 0 * * 1` | 회차 시작 안내 (활성 멤버 멘션) | `#공지사항` |

### 회차 시작 알림 상세

`round-start` 스케줄러가 매주 월요일에 실행되며:
- DB에서 `active` 상태 멤버만 조회
- 각 멤버를 `<@discordId>` 형태로 멘션
- 회차 기간 (`startDate ~ endDate`), 마감일, 지각 마감일 표시
- 임베드에 참여 인원 수 표시

### 개인 DM 알림

봇이 `user.send()`로 서버 멤버에게 직접 DM 발송. 유저가 서버 멤버 DM을 허용해야 동작.

| DM 종류 | 트리거 | 내용 |
|---------|--------|------|
| 벌금 리마인더 | 매일 10:00 (`fine-reminder`) | 미납 벌금 안내 |
| 출석 체크 | 매주 화 00:00 (`attendance-check`) | 이번 주 출석 결과 |
| 마감 리마인드 | 구현 필요 | "글 마감 D-3, D-1" |
| 주간 리포트 | 구현 필요 | 개인 활동 요약 |

## 5. 생성 후 설정

### 채널 ID를 DB에 등록

스크립트 실행 후 출력된 채널 ID를 DB에 등록:

```sql
-- 새 글 알림 채널
INSERT INTO study_configs (key, value)
VALUES ('announcement_channel', '채널ID')
ON CONFLICT (key) DO UPDATE SET value = EXCLUDED.value;

-- 큐레이션 브리핑 채널
INSERT INTO study_configs (key, value)
VALUES ('curation_channel', '채널ID')
ON CONFLICT (key) DO UPDATE SET value = EXCLUDED.value;
```

또는 웹 관리자 페이지에서 설정 가능 (구현된 경우).
