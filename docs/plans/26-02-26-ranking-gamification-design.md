# 랭킹 게이미피케이션 UI 디자인

## 목표
블로그 포스팅 개수 기반 랭킹을 게이미피케이션 UX로 개편하여 스터디원 간 경쟁심리를 자극한다.

## 접근법: 비주얼 강화 (B안)
DDL 변경 없이 기존 데이터(posts, attendance)를 활용한 시각적 게이미피케이션.

## 변경 사항

### 1. 포디움 (Top 3) - 높이 차이 시상대
- 2위(왼쪽) - 1위(가운데, 가장 높음) - 3위(오른쪽) 배치
- `items-end` 그리드로 실제 시상대 높이 차이 표현
- 1위: 골드 링 + 크라운 아이콘, 2위: 실버 링, 3위: 브론즈 링
- 각 카드에 포스트 수 + 출석률 + 스트릭 표시

### 2. 순위 변동 (Rank Delta)
- API에서 직전 라운드 기준 이전 순위 계산
- ▲ 초록 (상승), ▼ 빨강 (하락), — 회색 (유지) 표시
- 테이블 순위 열 옆에 배치

### 3. 연속 출석 스트릭
- attendance 테이블에서 최신 라운드부터 연속 'submitted' 횟수 계산
- 불꽃(Flame) 아이콘 + 숫자로 표시
- 포디움 카드 + 테이블 모두에 표시

### 4. 내 순위 하이라이트
- 로그인 유저의 테이블 행을 `bg-primary/5 ring-1 ring-primary/20`로 강조
- "다음 순위까지 N개" 격차 표시

### 5. 출석 히트맵 (미니)
- 각 멤버의 최근 회차 출석을 작은 도트(4x4px)로 표시
- 제출=emerald, 지각=yellow, 결석=rose, 대기=muted

### 6. 정렬 탭 확장
- 기존: 포스트 수, 출석률
- 추가: 이번 회차, 스트릭

## API 변경
`GET /api/ranking` 응답에 추가 필드:
- `currentStreak`: 연속 출석 횟수
- `rankDelta`: 직전 대비 순위 변동
- `attendanceHistory`: 최근 회차 출석 상태 배열
- `currentRoundPosts`: 현재 회차 포스트 수
